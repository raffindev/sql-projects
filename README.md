# SQL Projects

Coleção de projetos práticos desenvolvidos para estudo e consolidação de **SQL, bancos de dados, modelagem relacional e análise de dados**.

O repositório reúne projetos progressivos utilizando **MySQL e PostgreSQL**, explorando diferentes cenários e níveis de complexidade.

O objetivo é transformar o conhecimento teórico em prática por meio da criação de bancos de dados, modelagem, relacionamentos, consultas e análises baseadas em situações próximas às encontradas no mercado.

---

## 🎯 Objetivo

Este repositório faz parte da minha preparação prática em **SQL e bancos de dados**.

Os projetos foram organizados de forma progressiva, começando pelos fundamentos de modelagem e consultas relacionais e avançando para:

* Modelagem de bancos de dados
* Relacionamentos entre tabelas
* `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY` e `HAVING`
* `JOINs`
* Agregações e métricas
* Subqueries
* Funções SQL
* Análise de dados
* SQL analítico
* Modelagem para análise
* PostgreSQL
* Conceitos de Data Warehouse e BI

A proposta não é apenas escrever consultas, mas entender **como estruturar os dados e como extrair informações relevantes deles**.

## 🧠 Metodologia

Os projetos são desenvolvidos com foco em **prática e consolidação**.

Em cada projeto, busco trabalhar diferentes etapas do desenvolvimento de um banco de dados:

1. Definição do problema
2. Modelagem dos dados
3. Criação das tabelas
4. Definição dos relacionamentos
5. Inserção dos dados
6. Desenvolvimento das consultas
7. Análise dos resultados
8. Refatoração e organização do código SQL
9. Documentação do projeto

Conforme os projetos avançam, novos conceitos e desafios são introduzidos.
